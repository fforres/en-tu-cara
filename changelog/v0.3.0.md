En Tu Cara 0.3.0 — unmissable, fully-local meeting alerts for the macOS menu bar (Apple Silicon).

- First launch now actually asks for calendar and notification access — previously the macOS prompt never fired, so the app sat in a "grant access first" dead end with no way to grant.
- Settings → Calendars: when access hasn't been decided yet, a "Grant calendar access" button triggers the macOS prompt and reloads your calendars; if access was denied, it guides you to System Settings → Privacy & Security → Calendars.

Ad-hoc signed for now: on first launch right-click → Open (or System Settings → Privacy & Security → Open Anyway) until notarization is set up.
