En Tu Cara 0.3.1 — unmissable, fully-local meeting alerts for the macOS menu bar (Apple Silicon).

- First-run onboarding: a welcome window walks you through granting calendar and notification access, instead of bare permission prompts.
- New Settings → About tab: app version with a Check for Updates button, links to the source code and help/support, and a note that the app is free, open-source and volunteer-run.
- Now MIT-licensed.

Ad-hoc signed for now: on first launch right-click → Open (or System Settings → Privacy & Security → Open Anyway) until notarization is set up.
