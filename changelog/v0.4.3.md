En Tu Cara 0.4.3 — reliability & diagnostics polish on top of 0.4.2's calendar-access fixes (macOS, Apple Silicon).

Reliability:
- The menu-bar popover no longer flips the pause toggle or blanks your events on a transient calendar hiccup — a momentary read failure now preserves what's on screen instead of clearing it.
- The full-screen alert's "Join" button is more robust: if the calendar read blips at the moment the alert appears, it now retries instead of dropping the button.
- The context menu can no longer get clipped off the top-left edge of the popover.

Diagnostics (for when something looks wrong):
- Every log now opens by stating your calendar permission (FullAccess / Denied / NotDetermined) — the fastest way to spot the most common cause of "no events."
- A one-line note is logged whenever your calendar goes from having events to none (or back), so an empty list leaves a trace.
- Set ENTUCARA_LOG=debug before launching to capture detailed per-poll timing without a rebuild; the default stays quiet.

This release is mostly under-the-hood hardening — no changes to how alerts look or fire.

Ad-hoc signed for now: on first launch right-click → Open (or System Settings → Privacy & Security → Open Anyway) until notarization is set up.
