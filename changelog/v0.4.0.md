En Tu Cara 0.4.0 — unmissable, fully-local meeting alerts for the macOS menu bar (Apple Silicon).

Reliability hardening, so an alert can never silently go missing:
- The alarm engine now survives an unexpected internal error instead of quietly stopping — it keeps firing your alerts no matter what.
- An alert is marked "fired" only once its overlay is actually on screen; if showing it ever fails, the next check retries instead of swallowing it.
- Snoozes and already-dismissed alerts are saved atomically, so a crash or forced quit can't wipe them and make a meeting re-alert or get skipped.

Fixes & polish:
- Overlapping meetings: dismissing or snoozing one alert no longer closes the other.
- Zero-length (0-minute) calendar entries now get a "starting now" alert.
- First-run onboarding updates live — the moment you grant Calendar or Notifications access, the row flips to "Granted" on its own.
- Tightened security (content-security-policy + per-window permissions) and settings validation, so an out-of-range value can't break alerting.

Ad-hoc signed for now: on first launch right-click → Open (or System Settings → Privacy & Security → Open Anyway) until notarization is set up.
