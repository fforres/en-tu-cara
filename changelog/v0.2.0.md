En Tu Cara 0.2.0 — unmissable, fully-local meeting alerts for the macOS menu bar (Apple Silicon).

- Tray icon now opens a standard macOS menu (Open Settings · Quit) on left- or right-click; Settings opens as a normal, resizable window that no longer flashes white and matches your light/dark mode.
- Self-update: installed copies update automatically and show a notification when they do.
- Tray icon is configurable (Settings → Menu Bar → Tray icon: Auto / Light / Dark).
- Logs + a shared config folder at ~/.config/skyward/en-tu-cara (logs/, exports/).

Ad-hoc signed for now: on first launch right-click → Open (or System Settings → Privacy & Security → Open Anyway) until notarization is set up.
